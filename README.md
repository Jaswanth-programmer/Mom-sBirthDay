# ❤️ Mummy Birthday Website

This is a static GitHub Pages website.

## Repository structure

Everything is intentionally in ONE folder so you can upload the files individually:

- `index.html`
- `style.css`
- `script.js`
- `mom1.jpg`
- `mom2.jpg`
- `mom3.jpg`
- `mom4.jpg`
- `mom5.jpg`
- `mom6.jpg`

**Do not put the photos in a separate folder.**

## GitHub Pages

1. Create a GitHub repository and make it Public.
2. Click **Add file → Upload files**.
3. Select all 10 files above and upload them together.
4. Click **Commit changes**.
5. Go to **Settings → Pages**.
6. Under Source choose **Deploy from a branch**.
7. Choose `main` and `/ (root)`.
8. Click **Save**.
9. Wait a minute or two and open the generated GitHub Pages URL.

The website has no build command and no backend.
