# ❤️ Mummy Birthday Website

GitHub Pages-ready static birthday website.

All files are in the repository root — no photos folder is required.

Files:
- index.html
- style.css
- script.js
- mom1.jpg through mom6.jpg

The website content is in Telugu with a simple, warm tone.

## GitHub Pages
Upload all 9 files to the repository root, commit them, then:
Settings → Pages → Deploy from a branch → `main` → `/ (root)` → Save.
